# Aggie速记英语

一个面向家长和小学生的英语学习官网 + 学习体验 + 招生后台项目。

## 功能
- 官网首页：品牌介绍、课程体系、学习方法、招生报名、机构展示、视频展示
- 学习体验：国际音标、自然拼读、牛津英语、新概念英语、课内英语同步
- 学习练习：看图选词、听音选词、拼写练习、错词本、进度保存
- 招生后台：体验课、春季班、秋季班配置
- 机构展示：师资、地址、高德地图导航、周边环境、教学质量、周课表
- 媒体管理：真人发音上传、机构视频上传与展示

## 本地运行
```bash
npm install
npm run dev
```
