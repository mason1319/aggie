# Aggie速记英语

Aggie速记英语是一套面向家长与小学生的英语学习官网系统，集品牌展示、课程介绍、学习体验、招生报名、机构展示和媒体管理于一体。

## 项目定位
- 对外展示机构品牌、课程体系与教学实力
- 提供可直接体验的英语学习页面
- 支持体验课、春季班、秋季班招生展示
- 支持师资、地址、周边环境、教学质量和课表展示
- 支持真人发音与机构视频的本地上传管理

## 功能模块
- **官网首页**：品牌首屏、课程体系、学习方法、功能体验、招生专区、机构视频
- **学习体验**：国际音标、自然拼读、牛津英语、新概念英语、课内英语同步
- **学习练习**：看图选词、听音选词、拼写练习、错词本、进度保存
- **招生后台**：体验课、春季班、秋季班配置与展示管理
- **机构详情**：师资展示、高德地图导航、周边环境、教学质量、周课表
- **媒体管理**：真人发音上传、机构视频上传与首页展示

## 技术栈
- `Vite`
- `React`
- `TypeScript`
- `React Router`

## 本地运行
```bash

npm run dev
```
